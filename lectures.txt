SR latches, D latches, D flipflop
- SR latches
s= set, r=reset.
cross coupled NOR gates. pic in slides.
can't trigger set and reset at the same time.
storing 1 bit. press call button, light stays on; press again, light turns off.
therefore must take into account both input and current state - needs memory!
XOR(ButtonPressed?, Current state)
bit storage using an SR latch. 
remember that in practice that delays exist when values are getting updated! worry of oscillation - causing a glitch.
designer might try to avoid issue using external circuit.

 - level-sensitive SR latch
SR latch but with a clock added. only allows data to update when the clock is high.

 - D latches
level sensitive D latch - inserted inverter ensures R always opposite of S (reset automatically when 'set' is off)
stays value of D input until clock updates, then checks if new D value.
transparency - accepting changes to D for entire length of clock high. if too long a clock, d latch may erroneously update

 - D flipflop
d flipflop is similar to D latch except it updates on the clock edge not the clock signal
(posedge/negedge)
made of two D latches, linked up. diagram on slides.
solves issue for not knowing how many latches a signal travels through when clock=1

scan chain - chain of flipflops
also used in shifters (shifting binary left/right)

setup time - time needed to change input value
hold time - time taken til clock
clock-to-Q - how long til output is updated

if period is 20ns, frequency = 1/20 nanoseconds = 50 megahertz megahertz

register is a collection of flipflops in order.




FSM creation
finite state machine - a machine that has a finite number of states.
contains a register that stores the (value of) the current state.
contains combinational logic that is used to determine the next state.
the current state is what is coming out of the register.
state gets updated at clock edge.


 - Mealy machines
 output is function of the current state combined with the input.
 can have asynchronous outputs depending on input changes.
 output on edge from state to state: mealy machine

 - Moore machines - "Moore is Less/Less is Moore"
 output is function of the current state
 only clock-synchronous outputs.
 outputs only associated with states then moore machine.

State Transition Diagram (STD)
initial state: arrow going in from outside diagram.
edges: arrows pointing from state to state.
edges (arrows) labelled with the inputs required.

to make FSM truth table:
